## Entry

`main.ts` (Node 22, standard library only) copies the front page,
`entry.png` (1024×1024 PNG), to `/output/entry.png`. It reads nothing from
the network and writes nothing else, so two runs are byte-identical.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
